# Парсер врачей и слотов СМ-Клиники (Санкт-Петербург)

Сбор справочника врачей с НаПоправку и выгрузка в JSON/Excel. Дополнительно в проекте есть сборщик слотов с официального сайта СМ-Клиники.

Основной рабочий сценарий:

1. `sm-parser.py` собирает врачей, цены, статусы записи и свободные слоты по клиникам из списка.
2. `to_excel.py` превращает `doctors.json` в готовую таблицу `doctors.xlsx`.

## Что собирается

Для каждого врача:

- ФИО;
- филиал и адрес места приёма;
- специальности;
- рейтинг и количество отзывов;
- стаж и категория;
- взрослый/детский профиль;
- услуги и цены;
- статус записи;
- свободные даты и время приёма.

Проверенный результат на 08.11.2026 по филиалу «СМ-Клиника на Дыбенко»:

- 114 врачей;
- у 84 врачей есть расписание;
- 2 836 свободных слотов;
- 289 строк в Excel (одна строка = врач + услуга).

## Требования

- Python 3.10+;
- Playwright;
- Firefox для Playwright.

Сайт НаПоправку использует антибот-защиту Servicepipe. Chromium и WebKit получают страницу `Forbidden`, поэтому парсер работает через Firefox.

## Установка

### Windows

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m playwright install firefox
```

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install firefox
```

## Запуск

### 1. Сбор данных с НаПоправку

Все клиники из списка `BASE_URL` в `sm-parser.py`:

```bash
.venv/bin/python sm-parser.py
```

Windows:

```powershell
.venv\Scripts\python sm-parser.py
```

Один филиал для проверки:

```bash
.venv/bin/python sm-parser.py --url "https://napopravku.ru/spb/clinics/sm-klinika-na-dybenko/vrachi/"
```

Принудительно открыть окно браузера:

```bash
.venv/bin/python sm-parser.py --visible
```

Результат: `doctors.json`.

### 2. Выгрузка в Excel

```bash
.venv/bin/python to_excel.py
```

Результат: `doctors.xlsx`, лист «Врачи».

### 3. Слоты с официального сайта СМ-Клиники

```bash
.venv/bin/python sm_slots.py --visible
```

Несколько специальностей:

```bash
.venv/bin/python sm_slots.py --visible --specialty Кардиолог --specialty Терапевт
```

Все специальности:

```bash
.venv/bin/python sm_slots.py --all-specialties
```

Результаты сохраняются в `sm_output/` (CSV + история в SQLite + JSON-отчёт).

## Как работает антибот-защита

- Парсер запускает Firefox с постоянным профилем `data/.firefox-profile`.
- Cookies проверки сохраняются между запусками, поэтому обычно проверку достаточно пройти один раз.
- Если сайт всё же показал проверку, парсер распознаёт её и автоматически перезапускает Firefox с окном.
- После прохождения проверки сбор продолжается без потери данных.
- Если проверку пройти не удалось, парсер завершится с понятной ошибкой, а не сохранит пустой отчёт.

Профиль браузера не попадает в git и хранится только локально.

## Что делает `sm-parser.py`

1. Открывает страницу клиники.
2. Ждёт загрузки карточек и при необходимости проходит антибот-проверку.
3. Принимает cookie-баннер.
4. Прокручивает страницу и нажимает «Показать ещё», пока не загрузятся все врачи.
5. Разбирает карточки: ФИО, филиал, специальности, рейтинг, стаж, цены, статус.
6. Для врачей с записью открывает календарь и собирает свободное время по дням.
7. Сохраняет результат в `doctors.json` после каждого филиала.

## Структура `doctors.json`

```json
{
  "name": "Яковенко Ольга Игоревна",
  "filial": "СМ-Клиника на Дыбенко",
  "specialties": ["маммолог-онколог"],
  "rating": 5.0,
  "reviews": 147,
  "experience_years": 23,
  "category": "Кандидат мед. наук",
  "adults": "Взрослый",
  "prices": [
    {"service": "Прием маммолога", "price": 4800}
  ],
  "status": "есть запись",
  "slots_by_date": {
    "10.11": ["20:10", "20:50"],
    "11.11": ["17:30"]
  }
}
```

## Структура `doctors.xlsx`

| Колонка | Описание |
|---|---|
| Врач | ФИО |
| Филиал | Название клиники |
| Специальности | Специальности через запятую |
| Услуга | Название услуги |
| Цена, ₽ | Цена услуги |
| Ближайший слот | Ближайшая дата и время |
| Слоты на дату | Свободное время в первый доступный день |
| Кол-во слотов на дату | Количество слотов в первом доступном дне |
| Всего слотов | Всего слотов у врача |

Одна строка таблицы — это пара «врач + услуга». Если у врача несколько услуг, он занимает несколько строк.

## Параметры `sm-parser.py`

| Параметр | Описание |
|---|---|
| `--url` | URL для сбора. Можно указать несколько раз |
| `--visible` | Запустить Firefox с окном |

Без `--url` используются все клиники из `BASE_URL`.

## Файлы проекта

| Файл | Назначение |
|---|---|
| `sm-parser.py` | Основной парсер НаПоправку (врачи + слоты) |
| `to_excel.py` | Преобразование `doctors.json` в `doctors.xlsx` |
| `sm_slots.py` | Сбор слотов с официального сайта СМ-Клиники |
| `parser.py` | Ранний прототип сбора справочника в CSV |

| `doctors.xlsx` | Готовая таблица для менеджеров |
| `data/` | Служебные файлы и профиль Firefox |

## Ограничения

- Данные актуальны на момент запуска. Расписание может меняться в течение дня.
- Полный сбор по четырём клиникам занимает ориентировочно 20+ минут.
- Сбор одного крупного филиала занимает около 5–6 минут.
- Если сайт изменит разметку, парсер сообщит об ошибке или пропустит карточку.
- Парсер не создаёт записи к врачу и не нажимает кнопки подтверждения записи.
- При автоматическом запуске по расписанию первый запуск может потребовать окно браузера для прохождения проверки.
- Пустой список слотов не всегда означает, что записи нет: это может быть особенность отображения календаря.

## Автоматический запуск

### Windows (Планировщик заданий)

- Программа: полный путь к `.venv\Scripts\python.exe`;
- Аргументы: полный путь к `sm-parser.py`;
- Рабочая папка: папка проекта.

После сбора можно отдельной задачей запускать `to_excel.py`.

### macOS / Linux (cron)

Пример запуска каждый день в 08:00:

```cron
0 8 * * * cd /path/to/parser && .venv/bin/python sm-parser.py >> parser.log 2>&1 && .venv/bin/python to_excel.py >> parser.log 2>&1
```

## Если что-то пошло не так

**Вместо врачей страница `Forbidden` или проверка**

Запустите с окном и пройдите проверку:

```bash
.venv/bin/python sm-parser.py --visible
```

После успешного прохождения cookies сохранятся в `data/.firefox-profile`.

**Не установлен Firefox для Playwright**

```bash
.venv/bin/python -m playwright install firefox
```

**Профиль браузера занят**

Закройте все окна Firefox, запущенные парсером, и повторите запуск.

**Excel не сохраняется**

Закройте `doctors.xlsx` в Excel/LibreOffice и повторите `to_excel.py`.
